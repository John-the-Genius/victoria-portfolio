# Images folder

Add your photos here with these exact filenames so the site picks them up automatically:

- `profile.jpg` — hero portrait (used at the top of the page)
- `gallery-1.jpg` through `gallery-6.jpg` — the "On set & in frame" gallery grid

You can add more than 6 gallery photos — just add a new `<figure>` block in index.html
in the #gallery section, following the same pattern, pointing at e.g. `images/gallery-7.jpg`.

Recommended: keep photos under ~500KB each (resize/compress before uploading) so the
site stays fast, especially important on GitHub's free tier bandwidth limits.
